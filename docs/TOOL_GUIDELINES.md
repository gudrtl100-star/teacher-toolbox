# 도구 제작 규칙

새 도구를 만들 때 지킬 것들입니다. Claude에게 도구를 만들어 달라고 할 때 이 문서를 같이 읽히면 됩니다.

> 기존 도구 두 개(자리 배치·출결 점검기)도 2026-07-31에 같은 톤으로 맞췄습니다. 이때 **CSS만 바꾸고 HTML 구조와 JS는 한 글자도 건드리지 않았습니다.** 앞으로 기존 도구의 겉모습을 손볼 때도 같은 원칙을 지킵니다 — `<style>` 블록 안에서만 작업하고, 클래스명·id는 절대 바꾸지 않습니다. JS가 그 이름들을 참조하고 있습니다.

## 반드시 지킬 것

### 1. 단일 HTML 파일

CSS·JS를 한 파일 안에 넣습니다. 외부 CDN 스크립트를 부르지 않습니다.

> 이유: 학교 인터넷이 특정 도메인을 막는 경우가 있고, CDN이 죽으면 도구도 같이 죽습니다. 파일 하나면 USB로 옮겨도, 인터넷 없이도 돌아갑니다.

라이브러리가 꼭 필요하면(예: PDF 읽기) 그 코드를 파일 안에 붙여 넣습니다. 출결 점검기가 이 방식입니다. **다만 넣기 전에 크기를 먼저 따집니다 — 아래 2번.**

### 2. 파일은 가볍게 — 무거우면 아예 안 열립니다

**목표: 도구 하나 300KB 이내.** 학교 인터넷은 느립니다. 실제로 재보면 이렇습니다.

| 크기 | 압축 후 | 학교에서 여는 시간 |
|---|---|---|
| 126KB | 40KB | 1초 안 |
| 986KB | 354KB | 1~9초 |
| 2.3MB | 725KB | **14~25초** |

25초를 기다리는 사람은 없습니다. 창을 닫고 다시 안 옵니다.

**라이브러리를 파일 안에 넣기 전에 두 번 묻습니다.**

1. 그 기능이 **꼭 필요한가?** — 자리 배치는 엑셀 파일 업로드를 위해 862KB짜리 라이브러리를 넣었다가 뺐습니다. 명단은 **복사해서 붙여넣는 게 더 빠릅니다.** 기능 하나를 위해 도구를 8배로 불리지 않습니다.
2. **대체 흐름이 있는가?** — 엑셀 → CSV로 저장, 표 복사·붙여넣기. 교사가 이미 아는 방법이면 그걸 안내하는 게 낫습니다.

> ⚠️ **기능을 뺄 때는 대체 흐름이 진짜로 있는지 먼저 확인합니다.** 자리 배치에서 엑셀 업로드를 뺄 때 "붙여넣으세요"라고 안내했지만, 정작 **여러 명을 붙여넣을 칸이 없었습니다.** 이름 칸은 한 명씩 받는 한 줄짜리였습니다. 붙여넣기 칸(textarea)을 만들고 나서야 안내가 사실이 됐습니다.
>
> 엑셀에서 복사한 표는 **탭(`\t`)으로 나뉘고 줄 끝에 `\r`이 붙습니다.** 쉼표만 처리하는 파서는 붙여넣어도 안 읽힙니다. 첫 줄의 제목 행("번호 이름 성별")도 걸러야 가짜 학생이 안 생깁니다.
>
> ```js
> txt.split(/\r?\n/).forEach(l => { const p = l.split(/[\t,]/); ... });
> ```

출결 점검기(2.3MB)처럼 라이브러리가 **기능의 핵심**이면(PDF·엑셀을 읽어야 점검이 됩니다) 어쩔 수 없습니다. 대신 첫 화면이 미리 받아둡니다 — `assets/app.js`의 `prefetchTool()`이 목록에 마우스를 올리는 순간 파일을 받아둡니다.

> 확인하는 법: `ls -l tools/<도구>/index.html`. 300KB를 넘으면 무엇이 그렇게 큰지 찾아보세요.

### 3. 네트워크 전송 없음

`fetch`, `XMLHttpRequest`, 폼 전송, 외부 이미지·폰트 요청을 쓰지 않습니다.

> 이유: 학생 이름과 출결 기록을 다룹니다. "안 보낸다"가 아니라 **보낼 코드 자체가 없어야** 떳떳합니다. F12 → Network 탭이 비어 있는지 확인하세요.

글꼴은 **저장소 안에 있는 파일**(`assets/fonts/PretendardVariable.woff2`)을 상대경로로 부릅니다. 같은 저장소 파일이라 외부 요청이 아니고, 인터넷이 끊겨도 그대로 나옵니다. 자세한 선언은 아래 "디자인 톤"에 있습니다.

### 4. 개인정보 흔적 지우기

- 학생 명단 같은 입력은 `localStorage`에 저장해도 되지만, **"전체 초기화" 버튼을 반드시** 둡니다.
- 공용 컴퓨터에서 쓸 수 있다는 점을 안내 문구에 넣습니다.
- 저장 키는 도구별 접두사를 붙입니다. (`seat_`, `ac_` 등)

### 5. 최종 판단은 사람이

점검·검증 성격의 도구는 결과 화면에 이런 취지의 문구를 넣습니다.

> 놓친 항목이 있을 수 있습니다. 최종 확인은 선생님이 해주세요.

> 이유: 도구를 믿고 넘어갔다가 업무 사고가 나면 도구를 만든 쪽이 책임을 뒤집어씁니다. 도구는 **검토를 돕는 것**이지 결재하는 것이 아닙니다.

### 6. 처음 보는 사람이 혼자 쓸 수 있게

- 첫 화면에 **무엇을 해주는 도구인지** 한 문장.
- 준비물이 있으면(파일 등) 목록으로 보여줍니다.
- 3~5단계 사용 안내. "다시 보지 않기" 체크박스와 함께.
- 우측 하단에 `?` 버튼으로 안내를 다시 열 수 있게.

출결 점검기의 인트로 팝업이 이 형태입니다. 새 도구를 만들 때 그대로 가져다 쓰세요.

## 지키면 좋은 것

### 디자인 톤

첫 화면과 따로 놀지 않게 아래 토큰을 씁니다. **색은 액센트 하나뿐**이고, 위계는 색이 아니라 **글자 굵기와 여백**으로 만듭니다.

```css
:root {
  /* 표면 */
  --bg: #fbfbfd; --surface: #fff;
  --fill: rgba(0,0,0,.045); --fill-strong: rgba(0,0,0,.075);
  --sep: rgba(0,0,0,.09);
  /* 글자 — 3단계면 충분합니다 */
  --t1: #1d1d1f; --t2: #6e6e73; --t3: #8e8e93;
  /* 액센트 하나. "지금 누를 수 있는 것"에만 */
  --accent: #0071e3; --accent-soft: rgba(0,113,227,.1);
  /* 상태색은 꼭 필요할 때만 */
  --ok: #248a3d; --warn: #b25000; --err: #d70015;
  /* 여백 — 4의 배수 */
  --s1:4px; --s2:8px; --s3:12px; --s4:16px; --s5:24px; --s6:32px; --s7:48px; --s8:64px;
  --r-sm:10px; --r-md:14px; --r-lg:20px; --r-xl:28px;
  --ease: cubic-bezier(.32,.72,0,1);   /* 스프링에 가까운 곡선 */
}
```

**글꼴은 첫 화면의 것을 가져다 씁니다.**

```css
@font-face {
  font-family: 'Pretendard Variable';
  src: local('Pretendard Variable'),
       url('../../assets/fonts/PretendardVariable.woff2') format('woff2-variations');
  font-weight: 45 920; font-display: swap;
}
body { font-family: 'Pretendard Variable', -apple-system, 'Apple SD Gothic Neo', system-ui, sans-serif; }
```

### 타이포그래피 — 자간은 크기마다 다릅니다

전체에 `letter-spacing` 하나를 거는 건 어느 크기에선가 반드시 틀립니다. **큰 글씨는 좁히고, 작은 글씨는 넓힙니다.**

| 쓰임 | 크기 | 굵기 | 행간 | 자간 |
|---|---|---|---|---|
| 큰 제목 | 2.1–3.25rem | 700 | 1.07 | `-0.038em` |
| 부제 | 1.0625rem | 400 | 1.52 | `-0.014em` |
| 항목 제목 | 1rem | 600 | 1.3 | `-0.022em` |
| 본문 | 0.875rem | 400 | 1.5 | `-0.006em` |
| 캡션 | 0.75rem | 500 | 1.4 | `+0.01em` |

### 줄바꿈 — 읽다가 걸리는 자리에서 줄이 바뀌지 않게

한국어 문장을 그냥 흘려 쓰면 브라우저가 **아무 데서나** 줄을 바꿉니다. "여러 사람이 쓰는 / 컴퓨터라면"처럼 말 중간이 갈라지면 한 번에 안 읽히고, 읽는 사람은 이유도 모른 채 답답해합니다. 아래 다섯 가지를 지킵니다.

**1. 어절은 쪼개지 않습니다** — `body`에 한 번만 걸면 됩니다.

```css
body { word-break: keep-all; overflow-wrap: break-word; }
```

`keep-all`이 없으면 "필요 없으면"이 "필요 없 / 으면"으로 갈라집니다. 다만 긴 영문·주소는 넘치지 않게 `break-word`로 풀어 줍니다.

**2. 문장은 통째로 넘깁니다** — 한 문단에 문장이 둘 이상이면 문장마다 `<span>`으로 감쌉니다.

```html
<p class="sentences">
  <span>보낼 코드 자체가 없습니다.</span>
  <span>인터넷을 꺼도 그대로 됩니다.</span>
</p>
```

```css
.sentences > span { display: inline-block; }
```

`inline-block`이라 문장이 한 줄에 다 들어가면 나란히 붙고, 자리가 모자라면 **문장째** 다음 줄로 갑니다. 화면 폭이 얼마든 문장 중간이 갈라지지 않습니다.

**3. 갈라지면 뜻이 흐려지는 구는 묶습니다.**

```html
<span class="nowrap">3학년 5반</span>
```

```css
.nowrap { white-space: nowrap; }
```

날짜(`05/06`), 학반, 숫자+단위(`3건`), 버튼 이름(`전체 초기화`)처럼 **한 덩어리로 읽히는 것**에만 씁니다. 긴 문장에 걸면 화면 밖으로 넘칩니다.

**4. 마지막 줄에 한 단어만 남지 않게.**

```css
p, li { text-wrap: pretty; }
```

**5. 제목은 줄 길이를 비슷하게** — 큰 글씨일수록 들쭉날쭉이 눈에 띕니다.

```css
h1, h2 { text-wrap: balance; }
```

제목을 반드시 특정 위치에서 끊어야 하면 `<br>`을 직접 넣되, **좁은 화면에서도 어색하지 않은지** 확인합니다.

> **한 줄에 몇 자가 좋은가**: 한글은 **한 줄 25~40자**가 편합니다. 시트·팝업은 `max-width: 460px` 정도면 자연히 그 범위에 들어옵니다. 문단이 화면 전체 폭으로 퍼지면 다음 줄 첫 글자를 찾느라 눈이 헤맵니다.

> **확인하는 법**: 창 너비를 줄여 가며 줄이 어디서 끊기는지 봅니다. 말 중간에서 끊기면 문장을 더 짧게 쓰거나 `.sentences`로 감쌉니다. **글이 길어서 생긴 문제를 CSS로 막으려 하지 마세요.** 대개는 문장을 줄이는 게 답입니다.

### 모션 — 누르는 순간 반응합니다

- 버튼은 **누를 때**(`:active`) 반응합니다. 떼고 나서가 아닙니다. `transform: scale(.97)`, 100ms
- 화면 전환은 `var(--ease)` 곡선에 350~400ms. 튕김(오버슈트)은 **손으로 던지듯 끌어서 놓은 동작에만** 씁니다. 그냥 뜨는 창이 튕기면 어색합니다
- 팝업·시트는 **누른 버튼 자리에서 자라나고 같은 자리로 되돌아갑니다**(`transform-origin`을 트리거 위치로). 왼쪽에서 들어와 아래로 사라지면 방향 감각이 깨집니다
- `prefers-reduced-motion`이면 짧은 페이드로 대체합니다

```css
@media (prefers-reduced-motion: reduce) {
  * { transition-duration: .01ms !important; animation-duration: .01ms !important; }
}
```

### 아이콘

이모지를 쓰지 않습니다. **24×24 그리드, `stroke-width: 1.5`, 둥근 끝단**의 선 아이콘을 인라인 SVG로 그립니다. 이모지는 OS마다 모양이 다르고, 화면 전체를 가볍게 만듭니다.

### 화면 크기

- 교사가 쓰는 화면은 대부분 **노트북 또는 교실 TV**입니다. 1280px 기준으로 맞춥니다.
- 자리 배치처럼 교실에서 띄우는 도구는 **글씨를 크게**. 뒷자리에서 보입니다.
- 모바일 대응은 선택입니다. 안 할 거면 `devices: ['pc']`로 표시해 두세요.

### 되돌리기

지우기·초기화 같은 동작은 확인을 한 번 받습니다. 교사는 업무 중에 급하게 클릭합니다.

### 결과물 내보내기

- 좌석표 → 이미지 저장
- 점검 결과·명단 → 엑셀 또는 인쇄

브라우저 안에서만 쓰고 끝나는 도구보다, **결과를 가지고 나갈 수 있는** 도구가 훨씬 많이 쓰입니다.

## 아카이브로 돌아가는 링크

도구 **좌상단**에 넣습니다. 링크만 받아 도구에 바로 들어온 선생님도 다른 도구가 있다는 걸 알게 됩니다. 화살표는 이모지가 아니라 선 아이콘입니다.

```html
<a class="tb-home" href="../../index.html">
  <svg width="16" height="16" viewBox="0 0 24 24" fill="none" stroke="currentColor"
       stroke-width="1.8" stroke-linecap="round" stroke-linejoin="round"><path d="M15 5l-7 7 7 7"/></svg>
  <span>도구상자</span>
</a>
```

```css
.tb-home { display:inline-flex; align-items:center; gap:4px;
  padding:6px 10px 6px 7px; border-radius:9px;
  font-size:13px; font-weight:600; letter-spacing:-.01em;
  color:var(--t2); text-decoration:none;
  transition:background-color .18s ease, color .18s ease, transform .12s ease-out; }
.tb-home:hover  { background:rgba(0,0,0,.05); color:var(--t1); }
.tb-home:active { transform:scale(.97); }
```

모바일에서 제목이 가운데 정렬이라면 **아이콘만** 남기고 폭을 고정해 정렬을 유지합니다(자리 배치 도구가 이 방식입니다).

```css
.tb-home-icon { width:40px; height:40px; padding:0; gap:0; justify-content:center; }
```
