# 만들고 싶은 도구 목록

떠오를 때마다 적어둡니다. 다 만들 필요는 없고, **매년 반복되는 일**부터 고릅니다.

## 우선순위 후보

| 도구 | 하는 일 | 왜 필요한가 | 난이도 |
|---|---|---|:---:|
| 📝 **생기부 글자수 검사기** | 문장을 넣으면 글자수·byte를 실시간 계산, 초과분 표시 | 나이스 byte 제한(한글 3byte) 때문에 매번 잘라내는 작업이 생김. 여러 학생을 한 번에 붙여넣고 검사 | 하 |
| 👥 **모둠 편성기** | 인원·조건(성별 균형, 특정 학생 분리)에 맞춰 모둠 배정 | 자리 배치와 로직이 비슷해 재활용 가능. 수행평가 때마다 필요 | 중 |
| ⏱️ **수업 타이머** | 큰 화면 카운트다운, 모둠활동 시간 알림 | 교실 TV에 띄우는 용도. 만들기 쉽고 자주 씀 | 하 |
| 📊 **수행평가 채점표** | 루브릭 기준을 넣고 학생별로 클릭 채점 → 엑셀 내보내기 | 종이 채점표를 옮겨 적는 시간이 큼 | 중 |
| ✅ **제출물 체크리스트** | 명단에 체크하고 미제출자만 뽑아내기 | 동의서·과제 걷을 때마다 반복 | 하 |
| 🎯 **문항 배점 검산기** | 시험 문항별 배점을 넣어 총점 100점·난이도 분포 확인 | 출제할 때 배점 합이 안 맞는 실수 방지 | 하 |
| 📅 **학사일정 D-day** | 시험·수행평가·마감일 카운트다운 | 학기 초에 한 번 넣어두고 계속 봄 | 하 |
| 🗒️ **상담 기록장** | 학생별 상담 내용을 날짜별로 기록, 검색 | 개인정보 민감 — 브라우저에만 저장하고 내보내기는 파일로 | 중 |
| 🔢 **중3 수학 연습문제 생성** | 단원·유형·문항 수를 고르면 문제와 답안지 출력 | 보충 자료를 매번 만드는 수고를 줄임 | 상 |

## 나중에 검토

- 좌석표 기반 출석 체크 (자리 배치 결과 재활용)
- 학급 칭찬 기록 / 상벌점
- 학부모 문자 문구 만들기 (상황별 예문 모음)
- 성적 처리 검산기 (지필·수행 반영비율 확인)
- 시간표 위젯

## 고르는 기준

1. **1년에 여러 번 하는 일인가?** 한 번뿐이면 손으로 하는 게 빠릅니다.
2. **나 말고 다른 교사도 겪는 일인가?** 아카이브에 올릴 가치가 생깁니다.
3. **엑셀로 이미 되는 일은 아닌가?** 되면 만들지 않습니다.
4. **개인정보를 다루는가?** 다룬다면 오프라인 동작이 확실한지 먼저 확인합니다.
