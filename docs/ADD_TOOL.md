# 새 도구 추가하기

도구 하나를 아카이브에 붙이는 데 5분이면 됩니다.

## 1. 파일 넣기

`tools/` 아래에 **영문 소문자 폴더**를 만들고 도구 HTML을 `index.html`이라는 이름으로 넣습니다.

```
tools/timer/index.html
```

- 폴더명은 영문·숫자·하이픈만 씁니다. 한글 폴더명은 주소가 `%EC%88%98...`처럼 깨져 보입니다.
- 파일명은 반드시 `index.html`이어야 주소가 `.../tools/timer/`로 깔끔해집니다.
- 도구가 여러 파일로 나뉘면 같은 폴더 안에 함께 둡니다.

## 2. 목록에 등록하기

`data/tools.js`의 `TOOLS` 배열 맨 앞에 항목을 추가합니다.

```js
{
  id: 'timer',                                  // tools/ 폴더명과 같게
  name: '수업 타이머',
  tagline: '한 줄 설명. 카드에 보이는 문장',        // 40자 안쪽
  description: '상세 설명. "자세히"를 눌렀을 때 나옵니다.',
  category: 'lesson',                           // classroom | attendance | lesson | records
  tags: ['타이머', '모둠활동', '수업'],
  icon: 'timer',                                // 아이콘 키 (아래 목록 참고)
  path: 'tools/timer/index.html',
  version: '1.0.0',
  added: '2026-08-15',                          // 처음 올린 날
  updated: '2026-08-15',                        // 고칠 때마다 갱신
  status: 'stable',                             // stable | beta
  offline: true,                                // 네트워크 전송이 없으면 true
  devices: ['pc', 'mobile'],                    // 모바일에서 쓸 만하면 mobile 포함
  howto: [                                      // 3~5단계 사용법
    '시간을 정합니다.',
    '시작을 누릅니다.',
  ],
  note: '팁이나 주의사항 한 줄. 없으면 지워도 됩니다.',
},
```

### 필드 설명

| 필드 | 필수 | 설명 |
|---|:---:|---|
| `id` | ✅ | 도구 구분값. 즐겨찾기 저장에 쓰이므로 **한 번 정하면 바꾸지 않습니다** |
| `name` | ✅ | 카드 제목 |
| `tagline` | ✅ | 카드에 보이는 한 줄. "무엇을 해주는지"를 씁니다 |
| `category` | ✅ | 카테고리 id. 새 카테고리가 필요하면 `CATEGORIES`에 먼저 추가 |
| `icon` | ✅ | 아이콘 키. 이모지가 아닙니다 |
| `path` | ✅ | index.html 기준 상대경로 |
| `added` | ✅ | `YYYY-MM-DD` |
| `updated` | | 최근 수정일. 45일 안이면 카드에 **NEW** 배지가 붙습니다 |
| `status` | | `beta`면 카드에 베타 배지. 아직 못 믿을 도구에 붙입니다 |
| `howto` | | 상세 시트의 번호 목록 |
| `note` | | 상세 시트 아래 팁 상자 |

### 아이콘

이모지 대신 직접 그린 선 아이콘을 씁니다. `assets/app.js`의 `ICON_PATHS`에 있는 키 중에서 고릅니다.

| 키 | 모양 | 어울리는 도구 |
|---|---|---|
| `seating` | 칠판과 책상 격자 | 자리 배치, 좌석표 |
| `checklist` | 문서와 체크 | 점검, 확인, 대조 |
| `timer` | 시계 | 타이머, 시간 관리 |
| `group` | 사람 둘 | 모둠 편성, 명단 |
| `note` | 줄 있는 문서 | 기록, 작성 |
| `calendar` | 달력 | 일정, 날짜 |
| `chart` | 막대 그래프 | 통계, 집계 |
| `tool` | 기본 도형 | 위에 없을 때 |

맞는 게 없으면 `ICON_PATHS`에 새로 추가합니다. **24×24 그리드, `stroke-width` 1.5, 둥근 끝단**을 지켜야 나머지와 같은 결로 보입니다. Claude에게 "`ICON_PATHS`에 같은 규격으로 주사위 아이콘을 추가해줘"라고 하면 됩니다.

## 3. 확인하기

`index.html`을 열어 확인합니다.

- [ ] 카드가 보이고 아이콘·설명이 맞는가
- [ ] "열기"를 누르면 도구가 새 탭에서 뜨는가
- [ ] "자세히"의 설명이 처음 보는 사람에게 이해되는가
- [ ] 검색창에 도구 관련 단어를 넣으면 나오는가
- [ ] 카테고리 칩으로 걸러지는가

카드가 안 보이면 `tools.js`에서 **쉼표를 빠뜨렸거나 따옴표가 안 닫힌** 경우가 대부분입니다. 브라우저에서 `F12` → Console에 빨간 오류가 뜹니다.

## 4. 올리기

```bash
git add . && git commit -m "수업 타이머 추가" && git push
```

Git을 안 쓴다면 GitHub 웹에서 파일을 끌어다 놓아도 됩니다. [DEPLOY.md](DEPLOY.md) 참고.

1~2분 뒤 공개 주소에 반영됩니다.

## 도구를 뺄 때

`TOOLS` 배열에서 해당 항목만 지웁니다. 폴더는 남겨둬도 목록에 안 보입니다. 쓰던 사람이 있을 수 있으니 주소는 살려두는 편이 낫습니다.
